# LW Recipes Project (WordPress)

This repo was set up for a fictional recipes website named "Fit & Flavor", with the goal of providing code samples. Occasionally, some samples are built primarily to demonstrate something; in real life, it is possible that I would handle the building of the feature in a different manner. Where applicable, I note this in related documentation.

## Features
- Block theme that contains templates for: header, footer, index, recipe archive, and single recipe
- Custom blocks that are used in the aforementioned templates
- Metabox customization (Gutenberg)
- React app for a filterable list of recipes that is placed on the recipe archive page
