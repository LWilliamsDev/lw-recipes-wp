# Custom Metabox
When categorizing content, the Fit & Flavor Content Team would like all editors to only place their recipes in 1 course taxonomy and 1 diet taxonomy. Neither of these taxonomies are required, however, if an editor uses them, they should only assign 1 per recipe.

To accomplish this, I have removed the default editor panels for the course and diet taxonomies. I then added my own panels that use the SelectControl so that users can select only 1 term per recipe for each of these taxonomies.
