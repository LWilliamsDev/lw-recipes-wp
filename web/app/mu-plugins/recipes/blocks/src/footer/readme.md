# Global Footer

This block represents the global footer. In the [Recipes theme](../../../../../themes/lw-recipes/readme.md), it is added to the "footer" pattern. The footer pattern is then added to the footer template part.

## Child Blocks
- Social Media
  - Social Media Item

### Social Media
The Social Media block acts as a container that allows users to add social media items.

#### Social Media Item
The Social Media Item contains 2 fields in the block settings panel:

- Website Link
- Icon (choice of 4 icons)

This block was built with the understanding that the client would not have very many social media accounts to link to. A different solution would be needed for clients that need, say, the entire Font Awesome Brand library to choose from. If the user does not add both a website link and icon, a notice will appear in the block editor. Post saving and auto-saving will also be locked until the user adds a website link and icon.
